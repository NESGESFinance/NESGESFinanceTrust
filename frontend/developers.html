🚀 Inicio Rápido

La API de NESGESFinanceTrust expone datos de Bitcoin, Runes, Ordinals y activos RWA mediante REST API y WebSocket en tiempo real.

Base URL: https://api.nesgesfinancetrust.com
WebSocket: wss://ws.nesgesfinancetrust.com
Versión API: v1 (beta)

🔐 Autenticación

Algunos endpoints requieren autenticación mediante token Bearer o API Key.

POST
/auth/token
Obtener token de acceso
curl -X POST https://api.nesgesfinancetrust.com/auth/token \ -H "Content-Type: application/json" \ -d '{ "email": "tu@correo.com", "password": "tu_contraseña" }'
Respuesta:
{ "access_token": "eyJhbGciOiJIUzI1NiIs...", "token_type": "Bearer", "expires_in": 3600 }

Usa el token en el header Authorization: Bearer {token}

⛓️ Bloques

GET
/blocks/:height
Obtener información de un bloque por altura
GET /blocks/923867
Parámetros:
height number Altura del bloque (requerido)
Respuesta:
{ "height": 923867, "hash": "00000000...", "timestamp": 1724409600, "tx_count": 3250, "size": 1248576 }
GET
/blocks/recent
Obtener últimos 10 bloques indexados
GET /blocks/recent

⚡ Mempool

GET
/mempool
Obtener transacciones pendientes del mempool
GET /mempool
Query Params (opcionales):
limit number Máximo de resultados (default: 100, máx: 1000)
sort string fee_rate | time (default: time)
GET
/mempool/fees
Obtener estimaciones de fees actuales
GET /mempool/fees

🪙 Runes (Utility Token)

GET
/runes
Listar todas las Runes indexadas
GET /runes?limit=50&offset=0
GET
/runes/:name
Obtener información de una Rune específica
GET /runes/NGF•BTC•AM
GET
/runes/:name/holders
Obtener top 100 holders de una Rune
GET /runes/NGF•BTC•AM/holders

🏢 Activos Reales (RWA)

GET
/rwa/assets
Listar activos registrados con filtros opcionales
GET /rwa/assets?type=INMUEBLE&status=ACTIVO
Query Params (opcionales):
type string INMUEBLE | VEHICULO | ARTE | COMMODITIES | DEUDA | EQUITY
status string PENDIENTE | ACTIVO | TRANSFERIDO | CANCELADO
GET
/rwa/assets/:id
Obtener detalles de un activo
GET /rwa/assets/12345
GET
/rwa/assets/:id/history
Obtener historial de cambios de un activo
GET /rwa/assets/12345/history
POST
/rwa/assets
Registrar un nuevo activo (requiere autenticación)
POST /rwa/assets Authorization: Bearer {token} Content-Type: application/json { "name": "Propiedad Inmueble ABC", "type": "INMUEBLE", "description": "...", "valuationUSD": 250000, "location": "Ibarra, Ecuador", "documentHash": "a1b2c3d4..." }

📡 WebSocket (Tiempo Real)

Conecta a canales en vivo para recibir eventos en tiempo real.

WS
/ws
Conexión WebSocket con múltiples canales
// JavaScript const ws = new WebSocket('wss://ws.nesgesfinancetrust.com'); ws.onopen = () => { ws.send(JSON.stringify({ action: 'subscribe', channel: 'blocks' })); }; ws.onmessage = (event) => { const data = JSON.parse(event.data); console.log('Nuevo bloque:', data); };
Canales disponibles:
blocks — Nuevos bloques confirmados
mempool — Transacciones pendientes
runes — Eventos de Runes
ordinals — Nuevas inscripciones
rwa — Cambios en expedientes RWA

⏱️ Rate Limiting

Para asegurar estabilidad, la API implementa límites de uso:

100
req/min (público)
Limite para endpoints públicos sin autenticación
1,000
req/min (autenticado)
Limite para usuarios autenticados
10,000
req/min (premium)
Para integraciones empresariales (contactar)

Cuando alcances el límite, recibirás un error HTTP 429 (Too Many Requests). Reintenta después del tiempo especificado en header Retry-After.
