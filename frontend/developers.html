🚀 Inicio Rápido

La API de NESGESFinanceTrust expone datos de Bitcoin, Runes, Ordinals y activos RWA mediante REST API y WebSocket en tiempo real.

Base URL: /api
WebSocket: ws(s)://<host>/ws
Versión API: v3.4.0-dev

🔐 Acceso actual

Los endpoints públicos documentados en este repositorio no requieren autenticación. Las operaciones POST del módulo RWA permanecen bloqueadas en modo auditoría y responden HTTP 503.

GET
/health
Devuelve la identidad de la plataforma y el estado real de dependencias críticas.
GET /api/health

⛓️ Bloques

GET
/blocks/recent
Obtener los bloques más recientes persistidos.
GET /api/blocks/recent?limit=10
GET
/blocks/:height
Obtener información de un bloque por altura
GET /api/blocks/923867
Parámetros:
height number Altura del bloque (requerido)

📡 WebSocket (Tiempo Real)

Conecta a canales en vivo para recibir eventos en tiempo real.

WS
/ws
Conexión WebSocket con múltiples canales
const ws = new WebSocket(`${location.protocol === 'https:' ? 'wss' : 'ws'}://${location.host}/ws`); ws.onopen = () => { ws.send(JSON.stringify({ action: 'subscribe', channels: ['blocks', 'mempool'] })); }; ws.onmessage = (event) => { const data = JSON.parse(event.data); console.log(data.channel || data.type, data.payload); };
Canales disponibles:
blocks — Nuevos bloques indexados
mempool — Actualizaciones del mempool
runes — Eventos del protocolo Runes
ordinals — Eventos de Ordinals
rwa — Cambios del registro RWA
