📊 Descripción General
Cada activo real registrado en la plataforma sigue una máquina de estados definida. Los estados representan fases del expediente, y las transiciones son cambios causados por eventos (carga de documentos, aprobación, rechazo, tokenización, transferencia).

Detalles de Estados

PENDIENTE
Registro Iniciado
Usuario ha completado formulario inicial del activo. Plataforma asigna ID único y solicita carga de documentación.
Entrada: Formulario inicial
Salida: Puede cargar docs
Timeout: 14 días sin docs → CANCELADO
EN_REVISIÓN
Evaluación en Curso
Documentos cargados. Equipo evalúa completitud, autenticidad y relevancia. Puede solicitar documentación adicional.
Entrada: Documentos cargados
Duración: Hasta 30 días
Salida: Aprobación, rechazo o solicitud info
INFO_REQUERIDA
Información Requerida
Se requieren documentos o aclaraciones adicionales. Usuario tiene 14 días para responder, de lo contrario expediente se cancela.
Entrada: Solicitud de equipo
Plazo: 14 días
Salida: Reenvío de docs o CANCELADO
ACTIVO
Expediente Validado
Todos los criterios cumplidos. Expediente registrado oficialmente. Elegible para tokenización, marketplace y otros procesos.
Entrada: Aprobación final
Duración: Indefinida
Salida: Puede progresar a TOKENIZADO
TOKENIZADO
Activo Tokenizado
Activo ha sido estructurado en tokens. Ordinal asociado emitido. Disponible en marketplace y para transacciones.
Entrada: Proceso de tokenización
Resultado: Ordinal ID único
Salida: Puede transferirse a nuevo titular
TRANSFERIDO
Propiedad Transferida
Tokens transferidos a nuevo titular. Expediente archivado con registro completo de transferencia en on-chain.
Entrada: Transacción confirmada
Registro: TXID en Bitcoin
Estado: Inmutable
RECHAZADO
Expediente Rechazado
No cumplió criterios o documentación es fraudulenta/incompleta. Usuario recibe explicación de rechazo. No es elegible para procesos posteriores.
Entrada: Evaluación negativa
Notificación: Email con razones
Opciones: Apelar o iniciar nuevo expediente
CANCELADO
Expediente Cancelado
Usuario canceló manualmente o no respondió a solicitudes de información. Puede reiniciar nuevo expediente si lo desea.
Causa: Cancelación manual o timeout
Datos: Archivados 90 días
Reinicio: Puede crear nuevo registro

Transiciones Permitidas

→ PENDIENTE → EN_REVISIÓN
Condición: Usuario carga al menos un documento requerido
⏱️ Inmediato
→ EN_REVISIÓN → INFO_REQUERIDA
Condición: Evaluador solicita información adicional
⏱️ Manual (0-30 días)
→ INFO_REQUERIDA → EN_REVISIÓN
Condición: Usuario reenvía documentación solicitada
⏱️ Inmediato al reenvío
→ EN_REVISIÓN → ACTIVO
Condición: Todos los criterios de aceptación cumplidos
⏱️ Manual (0-30 días)
→ ACTIVO → TOKENIZADO
Condición: Usuario solicita tokenización y procesos internos completados
⏱️ 2-7 días
→ TOKENIZADO → TRANSFERIDO
Condición: Transacción Bitcoin confirmada (6+ confirmaciones)
⏱️ Inmediato al confirmar TXID
→ EN_REVISIÓN / INFO → RECHAZADO
Condición: Evaluador determina incumplimiento de criterios
⏱️ Manual
→ PENDIENTE / INFO → CANCELADO
Condición: Usuario cancela o no responde en plazo (14 días)
⏱️ Automático o manual

Tiempos Típicos de Transición

Transición Tiempo Mínimo Tiempo Máximo Trigger
PENDIENTE → EN_REVISIÓN Inmediato Inmediato Carga de documento
EN_REVISIÓN (completo) 1 día 30 días Evaluación manual
EN_REVISIÓN → ACTIVO 1 día 30 días Aprobación evaluador
ACTIVO → TOKENIZADO 2 días 7 días Solicitud usuario + procesos backend
TOKENIZADO → TRANSFERIDO 10 min Inmediato Confirmación blockchain (6+ conf)
PENDIENTE → CANCELADO 14 días 14 días Timeout automático
